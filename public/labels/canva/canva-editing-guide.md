# Fazendal Pinhal Canva editing guide

## 1. Upload the package

1. In Canva, create a **Custom size** design: **3000 × 3000 px**.
2. Upload `fazendal-pinhal-label.png` as the faithful print-reference artwork. Upload the SVG as well; it remains a sharp, scalable reference, although Canva may treat imported SVG text as a single graphic rather than independently editable text.
3. Upload `fazendal-pinhal-label-preview.png` only when you want to check the label against kraft paper. Do not use this file for printing.

## 2. Build an editable master template

Use the PNG or SVG as a locked visual guide while recreating the text with individual Canva text boxes. Hide or delete the reference once the editable layers are aligned.

- Background: add a full-bleed square in **Warm Ivory `#F6EEDC`**.
- Text: use **Deep Brown `#2E2019`**. Border and date rule: **Brown `#5A3826`**. Fine divider: **Warm Tan `#9B7155`**.
- Display font: **Cormorant Garamond Bold** (closest Canva match to the SVG’s Georgia treatment).
- Sans-serif font: **Montserrat** (use SemiBold/Bold for labels; Regular for regional detail).
- Use a 4 px rounded rectangle border inset about **126 px** from all sides (equivalent to 42 px in the SVG).

## 3. Text sizing and placement

All measurements below assume the 3000 × 3000 px Canva canvas. Centre all middle sections.

| Element | Font | Size | Position / treatment |
| --- | --- | ---: | --- |
| DRUNK | Cormorant Garamond Bold | 183 px | Top centre; letter spacing +8% |
| COFFEE ROASTERS | Montserrat Bold | 51 px | Below brand; letter spacing +22% |
| Coffee name | Cormorant Garamond Bold | 276 px | Largest text; two lines if needed |
| ORIGIN / TASTING NOTES | Montserrat Bold | 48–51 px | Uppercase; letter spacing +18–20% |
| Country | Cormorant Garamond Bold | 111 px | Centre |
| Region | Montserrat Regular | 60 px | Centre |
| Variety · Process | Montserrat Bold | 60 px | Uppercase, centre |
| Tasting notes | Cormorant Garamond Bold | 93 px | Centre |
| Footer | Montserrat Bold | 42–51 px | Bottom row |

Keep all live text inside the inner border and preserve at least **126 px** of outside safe margin. Use only the one thin divider between the coffee name and origin.

## 4. Reuse for another coffee

1. Duplicate the completed Canva page before editing.
2. Replace the coffee name, origin, region, variety/process, tasting notes, and roast date using `label-copy-template.md`.
3. If a line becomes crowded, reduce its font size slightly before changing the safe margins. Keep the coffee name as the dominant element.
4. Rename the page with the coffee name, then retain one untouched page called **Label master**.

## 5. Export for print

Download **PDF Print** with crop marks and bleed only if your printer requests them. For a raster workflow, choose **PNG**, set the largest available size, and confirm the artwork is 3000 × 3000 px or larger. The label has an intentional safe margin, but your printer should still confirm final bleed/cut-line requirements.
